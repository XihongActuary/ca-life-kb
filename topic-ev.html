§E.1内含价值 EV 框架核心

内含价值（Embedded Value, EV）= 分配给股东的、现有业务所产生的价值，是寿险公司估值与绩效评估的核心指标。
EV = 调整后股东净资产(ANW) + 有效业务价值(VIF)VIF（Value of In-force Business）= 现有保单未来股东现金流现值 − 持有要求资本的成本。市场一致内含价值 MCEV 进一步区分可对冲/不可对冲风险并显化资本成本。
组成含义
调整后净资产 ANW股东净资产，剔除与业务无关/不可分配部分
有效业务价值 VIF（扣前）未来股东现金流现值（未扣资本成本）
持有要求资本成本为支撑最低资本而占用资本的机会成本
VIF（扣后）扣前 − 持有资本成本

§E.2有效业务价值与 MCEV常考

MCEV（市场一致内含价值）在 EV 基础上，用市场一致假设计量，并将风险资本成本、不可对冲风险显式体现，更贴近市场估值。
MCEV = 调整净资产 + 市场一致有效业务价值 − 资本成本 + 新业务期权价值(可选)考虑「时间成本与不可对冲风险成本」是 MCEV 与传统 EV 的关键差异（见 2014 选择题 MCEV 计算）。
2014·3MCEV 计算：要求资本 90 亿，无风险利率 1.75%、溢价 25bp，给出 2014–2018 各年可分配盈余、两利率情景（1%/2%）→ 求有效业务价值。
骨架：①用风险贴现率(无风险+溢价)贴现各年可分配盈余；②持有资本成本=资本×贴现率；③有效业务价值=盈余现值−资本成本；④两情景取合理加权。

§E.3风险贴现率（CAPM 与影响因素）高频

r = r_f + β·(E[R_m]−r_f)　[CAPM]风险贴现率 = 无风险利率 + 风险溢价；β 反映系统性风险。
影响因素（教材 P500）方向
系统风险（β）越高 → 贴现率越高 → EV 越低
公司规模规模大→分散效应→较低
内部管理治理好→风险低→较低
业务质量保障型占比高→波动大→较高
资产质量资产稳健→较低
2014·9影响内含价值风险贴现率的因素？
骨架：系统风险、公司规模、内部管理、业务质量、资产质量（五类）。风险贴现率下降→未来现金流现值上升→EV 上升。
2016·20风险贴现率的定义？用什么模型确定？影响因素？EV 的缺陷？
骨架：①定义=将未来盈余折为现值的利率；②CAPM 或监管/公司指定模型；③五因素（见上）；④EV 缺陷（见 §E.7）。

§E.4压力测试常考

对 EV 施加不利情景（如资本要求翻倍），检验价值韧性。常见情景：利率下移、权益下跌、退保飙升、资本要求提高。
2015秋·11调整后股东净资产 20.9、RC=15.6、扣前有效业务 234.6、扣后 216.6；压力测试资本要求 200% → 求此时 EV。
骨架：压力后 RC=15.6×2=31.2；持有资本成本随 RC 同比例上升（18→36）；EV=20.9+234.6−36=219.5（正常 EV=20.9+216.6=237.5）。

§E.5新业务指标：NBV / NB Strain / 收支平衡 / ROC核心

指标含义管理用途
新业务价值 NBV/NBEV新单未来股东现金流现值（扣资本成本）增长质量
新业务压力 NB Strain新业务占用资本 / 可用资本（常为负）资本效率
收支平衡年度新业务累计利润转正所需年数回收速度
资本回报率 ROC利润 / 占用资本资本回报
2014·20四方案（NBEV/ NB Strain/ 收支平衡年/ ROC）各异；三情景分别选哪方案？
骨架：①ROC要求≥19%且资本紧张、不希望长期占用→方案1(ROC20%、NB Strain−16%、平衡6年)；②担心早期退保→方案2(平衡3年最短)；③资本充足、ROC≥18%→方案3(ROC21%、NBEV160最高)。

§E.6广义资本回报率（GCRR）常考

广义资本回报率衡量股东资本的综合回报，常结合借款利率与现金流情景给出「范围」。
GCRR = (股东收益 − 资本成本) / 平均股东资本　（多情景取范围）给定借款利率与多年现金流，GCRR 通常表现为一个区间（见 2014·15、2016·2）。
2014·15给定借款利率 8% 与各年现金流，求广义资本回报率的范围。
骨架：①分别按乐观/悲观现金流算 GCRR；②取区间；范围反映资本回报的不确定性。

§E.7利源分析深化与 EV 缺陷常考

利源分析（死/费/利/退保差）不仅用于利润拆解（见 CH.05），也是 EV 敏感性分析的输入；但 EV 本身有局限。
EV 缺陷（教材 P509 / 2016·20）
①忽略未来新业务价值（仅含存量）
②高度依赖精算假设（死亡率/贴现率/退保），假设敏感
③资本成本计量口径不一，跨公司可比性差
④不反映全部经济资本成本与治理质量
实务衔接：EV 常与新业务价值（NBV）合并为「EV + NB」评估公司总价值；分红决策以 VIF 与利源分析为据（见 CH.05 §5.4）。
要点一句话：内含价值 = 调整后净资产 + 有效业务现值（扣资本成本）；风险贴现率看五因素；压力情景下要求资本放大是 EV 侵蚀的主通道。
