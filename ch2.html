§2.1准备金概念与构成常考

责任准备金 = 公司为履行未来保险责任而提存的负债，是寿险公司资产负债表上最大的一项负债。教材 §9.2 按险种给出七套规定，先立整体框架。
分类含义对应精算规定
未到期责任准备金短险（意外/健康）未期满部分的负债671号（短期意外）、8号（健康）
未决赔款准备金已报案未付 + IBNR + 理赔费用准备金非寿按链梯/案均等法
寿险责任准备金长期寿险/年金未来给付现值缺口（核心）90号（传统）、67号（分红）、335号（万能投连）
长期健康险责任准备金长期重疾/医疗准备金8号（健康）+ 重疾表（2020）
寿险责任准备金 Vt = PV(未来给付 + 未来维持费用) − PV(未来净保费)
教材 §9.2 主线：先按险种选规定，再按修正法处理首年，最后用 GPV 检验充足性。

§2.3非分红传统寿险：一年期完全修正法（FPT）高频

首年佣金等获取成本前置，均衡净保费法首年准备金过高（甚至为负贡献失衡）——监管用一年期完全修正法（Full Preliminary Term）重新分配保费。

FPT 的两步构造（教材 §9.2.2）

① α = 首年自然净保费（一年期定期死亡净保费，仅覆盖首年风险）　⇒　第一年末准备金 = 0
② β 由精算现值等式反解：α + β·(äx − 1) = P·äx　⇒　β = (P·ä − α)/(ä − 1)
α+β 均为修正净保费；等式含义：修正前后净保费总现值不变——负债总量不动，只重排首年。

非分红传统险评估要点（教材 §9.2.2 五要点）

要点规则
修正法一年期完全修正（FPT）：首年末准备金为 0；终身年金类用修正净保费法，修正系数 r：个人业务 0.35、团体业务 0.15
评估利率取「监管公布评估利率」与「保单预定利率」中的较低者（教材时代公布值为 7.5%；1999.6 之后签发保单预定利率上限 2.5%）
生命表非养老金业务用非养老金生命表、养老金业务用养老金生命表（118号），选取从审慎角度（保守取向）
保费不足准备金当保单未来保费不足以支付未来给付与费用时，需额外计提保费不足准备金补足缺口
现行规则衔接保监发〔2017〕23号：评估利率=国债 750 日移动平均（基础利率）+综合溢价，受预定利率与上限约束；银保监办发〔2020〕7号承接普通型精算规定

§2.4分红险：FPT 与 Zillmer 3.5% 孰大必考

分红险的评估采用「两种修正法结果取大」——一年期完全修正（FPT）与 Zillmer 3.5% 摊额修正法并行计算，取准备金较大者入账。
Zillmer 修正：α = PNL − EA，其中费用津贴 EA ≤ 保单面额 × 3.5%；β 相应上调，保持净保费总现值不变
计提规则：V = max( VFPT , VZillmer )
教材 §9.2.3：分红险首年费用津贴上限为保额的 3.5%（Zillmer 摊额）；取大原则保证负债不因修正方法选择而低估。

分红险另外两条监管线

  • 分红特储（分红保险特别储备）：用于平滑各年红利水平；当年可分配盈余分配给保单持有人的比例不低于 70%，其余可留存特储。
  • 生命表与利率：死亡率按 118 号生命表（非养老金/养老金分表）；评估利率较传统险可上浮（综合溢价更小），因为红利机制本身承担部分投资风险。
对比记忆：非分红 = 单一 FPT；分红 = FPT 与 Zillmer 3.5% 取大。原因：分红险获取成本更高（演示、销售支持），Zillmer 给了更贴近真实的费用摊销路径，但监管不允许比 FPT 更激进的负债口径，故取大。

§2.5万能险与投连险：账户 + 非账户两分常考

新型产品的准备金一分为二：看得见的账户（负债=账户价值），与看不见的非账户（未来不保证利益的承诺）。
组成计量内容
账户准备金= 保单账户价值（逐期结算递推）保费入账、结算利息、扣风险保费与管理费后的余额——过去法思想的直接应用
非账户准备金未来法贴现未来结算利率超过最低保证部分的承诺、死亡给付超过账户价值部分（风险净额）、退保费用的资本化等
万能非账户准备金 ≈ PV(未来结算利益承诺 − 未来结算收入) + PV(风险净额给付缺口)
335号规定：万能结算利率需有资产支撑（不允许长期「虚高结算」）；投连则无保证利率，非账户部分主要是费用与死亡给付承诺。
实务提示：结算利率 = 账户实际投资收益率的市场化体现，但监管要求非账户准备金对「结算高于保证」的可持续性做压力测试——这是 19 号万能新规（见 CH.05 §5.8）评估专报的由来。

§2.6健康险与短期险评估基础

险种评估方法依据
长期健康险（重疾/护理）未来法 + 发生率表（重疾表 2020：保监发〔2020〕51号）；发生率不得低于下限8号 + 银保监办发〔2020〕7号
一年期及以下意外险未到期责任准备金按风险分布法（1/365、1/24 法）；未决按逐案/案均671号
短期健康险同非寿口径：保费不足测试 + 未决赔款准备金8号
一个易混点：「长期健康险」准备金用寿险式未来法贴现（现金流长期）；「短期健康/意外」用非寿口径（1/24、损失率法）——分界线是保险期间一年 + 是否含发生率为长期的保证。

§2.7再保险合同准备金评估（专节）新增

考纲二明确列「再保合同责任准备金评估」——分入与分出两个方向，方向不同、科目不同、方法同源。

分入业务（公司作为再保人）

科目评估要点
分保未到期责任准备金按分入险种对应原保险精算规定评估（传统90号/分红67号…对号入座），按分保账单保费比例归属
分保未决赔款准备金依据分出公司报送的赔案信息评估 IBNR；账单滞后（季度/年度）需滚动估计
保费不足测试分入保费不足以覆盖分保赔付+分保费用时计提保费不足准备金
纯益返还（经验账户）合同约定纯益手续费（P438）——分入利润的一定比例返还分出公司，评估负债时需预提

分出业务（公司作为分出人）

科目评估要点
摊回未决赔款准备金按再保合约比例可从再保人摊回的部分，确认资产（或冲减负债），需扣减再保人信用折扣
摊回未到期责任准备金比例再保下按分出比例摊回，与分出保费对应对冲
再保人信用风险摊回资产需评估再保人违约风险（偿二代信用风险最低资本，见 CH.03）；再保人评级下降触发额外折扣
分出摊回比例再保：摊回准备金 = 原保险准备金 × 合约分出比例（逐合约、逐险种）
非比例再保（超额赔款/停止损失）：按合约责任层评估摊回，通常对巨灾场景单独测试（PML）。
2016·再保（真题原型，简答）题干：某比例再保险合同约定纯益返还（纯益手续费）条款。请简述纯益返还条款的机制设计、分入方与分出方各自的准备金/资产评估含义，并说明该安排对再保险人风险敞口的影响。
骨架：①分保合约约定：分入利润的一定比例返还分出公司（激励审慎分出）；②分入方按经验账户预提纯益返还负债；③分出方对应确认应收纯益返还——科目对称、方向相反。
完整答题过程
问作答要点
①机制合约期末按分保经验（保费−赔付−费用）核算纯益，按约定比例（如 20%~30%）返还分出公司
②评估分入人按已赚分保费与已决+IBNR 估计滚动预提；分出人对应确认资产
③风险返还安排使分入人保留部分承保风险，评估时需与信用风险、合约滚动续保概率联动
溯源：2016 年真题再保险合同题（回忆版）；纯益手续费机制见教材 P438 再保险章节。
一句话贯通：再保评估 = 原保险评估 + 「方向对称 + 信用折扣」六个字。分入做负债、分出做资产，方法照搬原险种规定，再叠加再保人信用与账单滞后两个修正。

§2.8GPV 充足性分析（121号）必考

法定准备金是否够用，不看方法看检验：GPV（保单未来盈余现值）法是全险种通行的充足性底线。
GPV = PV(将来保险利益支出) − PV(将来保费收入)
判别：GPV ＜ 法定准备金　⇒　法定准备金充足（含退保金、红利、获取及维持费用）
教材 §9.2.4：支出含退保金与红利（与分红政策一致），费用假设不含一般间接管理费用（敏感性分析才纳入）。

四类业务的充足性方法（教材 §9.2.4）

业务类型充足性方法
长期业务（寿险/年金/长期健康）GPV 最低要求：法定准备金 ≥ GPV
未决赔款逐案检视，说明未决估计的合理性（无需 GPV）
一年期可续保业务同 GPV 框架，按续保假设评估未来保单年度
极短期业务损失率法：预期赔付率不超过定价赔付率

GPV 假设选取三原则

  • 贴现率：反映对应资产组合的预期投资收益（不是法定评估利率的机械套用）。
  • 红利假设：与公司分红政策、演示水平保持一致（不能假设永不分红）。
  • 费用假设：直接费用纳入；一般间接管理费用仅在敏感性分析中考虑。

准备金不足的四大典型原因（教材）

① 投资回报率低于定价假设（利差损侵蚀）；② 寿命延长低估年金负债（长寿风险）；③ 新疾病谱/发生率恶化（重疾）；④ 巨灾累积赔付超出预期。

§2.9资产份额法（Asset Share）大题

资产份额 = 每张有效保单对应的资产累积值。它是定价利润检验与「准备金不影响利润」证明的核心工具——2015秋·18 十分大题的考点。
ASt = [ ASt-1·(1+i) + P·(1+i) − 首年佣金 − 管理费·(1+i) − q·DB − s·CSV ] / 在保率
AS：单位资产份额；P 保费；q 死亡率；s 退保率；DB 死亡给付；CSV 退保金；分母=年初在保保单的存活比例。
真题数据（2015秋·18）：保额1000、年交保费187、年管理费6、首年佣金10%、投资收益率5%；退保率首年15%/次年2%/其后0；死亡率首年0.3%/其后0；有效因子首年0.849745/其后0.83275；退保价值首年158/次年345；准备金164/348/511/718/1000。三问：第三年末资产份额、0时利润现值、证明准备金不影响利润。

资产份额法演算器（2015秋·18 数据）

易错：资产份额是「资产」侧累积、准备金是「负债」侧计量，二者方向相反但服务于同一未来给付。当投资收益率恰为折现率时，AS 与 V 的差额（利润）在 0 时点的现值恰好为 0——这就是「准备金不影响利润」的证明内核。
完整答题过程：2015秋·18 三问全解（表格化）

第（1）问：第三年末资产份额

步骤计算
首年末AS₁×N₁：期初收保费187、扣佣金18.7与管理费6，按5%生息，扣死亡0.3%、退保15%×158 → N₁=0.849745，AS₁ = [ (187−18.7−6)×1.05 − 0.003×1000 − 0.15×0.997×158 ] / 0.849745 ≈ 167.0
次年末期初 AS₁×N₁+187N₁−6N₁ 生息 → 扣退保2%×345 → N₂≈0.8328，AS₂≈347.7
第三年末同样递推（无退保无死亡）→ AS₃ ≈ 577.2

第（2）问：以投资收益率折现的 0 时利润现值

利润现值 = Σ v^t·[ (ASt−Vt) − (ASt-1−Vt-1)(1+i) ]；用 AS₃−V₃=577.2−511=66.2 逐期回代，各期增量利润按 5% 折现加总——0 时点的结果与保费设计目标一致（该题保费 187 即按 5% 利率精算定价，利润现值≈0）。

第（3）问：证明准备金不影响利润

当折现率 = 投资收益率 i = 5% 时，资产累积与负债贴现同率：AS−V 的任何期初存量在期末按同一利率增长，逐期增量利润折现后互相抵消，Σv^t·Δ(AS−V) = Σv^t·[非利差利源]。即：准备金的计提与释放本身不创造利源，利润仅来自死差、费差、退保差——这正是 CH.05 利源分析的定价学基础。

① 评估利率：从「一个数」到「一条曲线」（保监发〔2017〕23号）

要素内容为什么这样设计
基础利率曲线国债 750 日移动平均收益率曲线约 3 年观察窗：平滑短期利率波动，同时保留趋势敏感性——既不追涨杀跌，也不装聋作哑
综合溢价基础曲线 + 溢价，传统险溢价 ＞ 分红险溢价补偿流动性、税收与违约损耗差异；分红机制自身吸收投资波动，故溢价可更小
封顶约束评估利率 ≤ 预定利率（取低）防止贴现口径比定价更激进——评估永远不比定价更乐观
曲线形态期限越长利率越低（正常向上期限结构）长久期年金负债贴现更「贵」，利率风险由此进入 CH.03 利率风险最低资本

② 三法准备金形态对比（同一保单、三种修正）

方法首年末 V₁形态监管定位
均衡净保费法最高（首年净保费超过自然保费，差额立即累积）平滑上升理论基准；但忽略获取成本前置，首年利润被压低
FPT= 0从零爬升、首年最松非分红传统险法定方法
Zillmer（EA ≤ 保额 3.5%）介于两者之间首年计提低于均衡、高于 FPT（通常）分红险与 FPT 取大入账
深挖要点：三法的负债总现值恒等（修正不改变净保费总量），不同的只是首年「形态」——首年末准备金越低，首年利润越高、新业务资本占用越少。监管允许 FPT/Zillmer 正是为了让评估反映真实的费用前置结构；「取大」则守住不低估负债的底线。这也是利源分析中「费差在首年集中释放」的评估学根源（专题·三差）。

③ 现金价值与保费不足准备金（90号的两条护城河）

  • 现金价值下限：现金价值计算基础须与准备金评估基础同源（同生命表、同利率），并对低现金价值产品设定最低比例要求——退保金不得随意压低，保护退保人权益。
  • 保费不足准备金（PMR）：当未来保费 + 现有准备金不足以覆盖未来给付与费用时，补提差额——是「费差损显形」的法定通道。
  • 与 GPV 的分工：PMR 管「按监管假设算出的缺口」（规则化）；GPV 管「按公司真实假设算出的底线充足性」（市场化）——一个对监管交代、一个对自己交代，互为补充。

教材落点：§9.2 表 9-5 及其前后文；23号曲线与现金价值规定详见 参考资料库。

自测真题印证与自测考前必做

先遮住答案独立作答，再展开核对——本章权重 20%，自测以一道计算 + 一道论述闭环，均对照真题命题口径（12 分制）。

自测 1（计算，12 分）：FPT 修正净保费 β 的求解与形态判断
某非分红传统两全保险，均衡净保费 P = 17.0 元，保费现值因子 ä = 8.5，首年自然净保费 α = 1.7 元。
求：①修正净保费 β；②判断 β 与 P 的大小关系并解释经济含义；③说明首年末准备金的取值与后续年度的形成过程。
①β = (P·ä − α)/(ä − 1) = (17.0×8.5 − 1.7)/(8.5−1) = (144.5 − 1.7)/7.5 = 142.8/7.5 = 19.04 元（4 分）；
②β = 19.04 ＞ P = 17.0：首年只按自然净保费 α = 1.7 计提，首年「少提」的净保费差额 15.3 元由续年每年多缴（19.04 − 17.0）≈ 2.04 元分期补回（4 分）；
③首年末准备金 = 0（FPT 定义使然）；续年 β 与当年自然保费的差额逐年累积，形态从零爬升，至期满前达到满期给付责任水平（4 分）。
评分要点：公式书写 3 分、β 数值正确 3 分、大小关系与经济含义 4 分、形态描述 2 分。
自测 2（论述，12 分）：GPV 充足性判断与假设选取原则
某分红险有效业务：法定准备金 8.2 亿元；按公司分红政策与对应资产组合预期收益率测算的 GPV = 7.6 亿元。
要求：①判断充足性并给出依据；②说明 GPV 测算中贴现率、红利假设、费用假设的选取原则；③若预期投资收益率下调 50bp，GPV 与充足性结论如何变化，公司可采取哪些应对动作。
①GPV = 7.6 亿 ＜ 法定准备金 8.2 亿，按 121 号判别式，法定准备金充足，安全余量 0.6 亿元（4 分）；
②三原则：贴现率反映对应资产组合的预期投资收益（非机械套用法定评估利率）；红利假设与公司分红政策、演示水平一致（不能假设永不分红）；费用假设只含直接费用，一般间接管理费用仅在敏感性分析中纳入（4 分）；
③贴现率下调 → 支出现值上升幅度大于保费收入现值（负债久期更长）→ GPV 上升；若升破 8.2 亿则转为不足，需补提准备金。应对：调降红利演示与实际分配水平、动用分红特储平滑、优化资产组合提升收益、必要时收缩高成本渠道（4 分）。
结论句：GPV 是「按公司真实假设」的充足性底线——法定口径通过，不等于商业口径稳赚；利率下行是分红险充足性的第一压力源。
