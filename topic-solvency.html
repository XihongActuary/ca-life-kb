§1案例总览：一张表看懂全链路高频

C-ROSS II 的计算题，本质上就是一条「负债 → 资本 → 充足率」的流水线。先把全链路背下来，再逐段演算。
步骤算什么案例数值依据
①三大量化风险模块最低资本（各自内部已按子风险相关性分散）保险 14,200 / 市场 11,800 / 信用 3,600规规则Ⅱ 第2号
②跨模块相关矩阵加总（ρ=0.25，k=0.0625）最低资本 MC = 20,081规规则Ⅱ 第2号
③实际资本 = 认可资产 − 认可负债；分级限额240,000 − 183,000 = 57,000规规则Ⅱ 第3号
④偿付能力充足率（核心 / 综合）核心 233% / 综合 284%规规则Ⅱ 第1号
⑤压力测试（股票 −30%、利率 −100bp、逆周期叠加）最低 165% / 201%规监管压力情景
⑥IRR 风险综合评级（A/B/C/D）A 类 83.1 分规规则Ⅱ 第11/12号
要点一句话：三大风险先各自量化，再经相关性矩阵聚合归一（分散效应释放资本）；实际资本分级、核心与综合两条充足率线并行，外加风险综合评级与压力测试。

§2第一步：三大量化风险模块

每个模块内部的子风险（如保险风险里的长寿 / 疾病 / 退保；市场风险里的利率 / 权益 / 房地产）先按各自的相关矩阵分散完毕，得到三个「模块级」最低资本。
风险模块主要子风险案例数值特征系数（定性）
保险风险最低资本 MCins损失发生 / 退保 / 费用等；寿险关注长寿、疾病发生率14,200与业务量同向放大，分散效应弱
市场风险最低资本 MCmkt利率 / 权益 / 房地产 / 汇率11,800资产端主导，久期错配是核心驱动
信用风险最低资本 MCcred利差 / 交易对手违约3,600与持仓信用等级、集中度挂钩
考试要点：控制风险最低资本与附加资本不进入量化风险矩阵，单独叠加。量化的三大模块才做相关性分散。

§3第二步：相关矩阵与最低资本高频

MC = √( MCins² + MCmkt² + MCcred²
  + 2ρmc·MCmkt·MCcred
  + 2k·MCins·(MCmkt + MCcred) )
ρmc = 0.25（市场×信用）；k = 0.0625（保险风险与市场/信用之间的量化相关性调整因子）。控制风险与附加资本在矩阵之外单独加回。

项算式结果
保险平方项14,200²201,640,000

信用平方项3,600²12,960,000
市场×信用交叉2×0.25×11,800×3,60021,240,000

案例口径 20,081 与手算 20,062 的微小差异来自各模块内部子风险相关性的舍入——考试写出演算逻辑即可拿分。
实务视角：简单加总 29,600 → 相关矩阵后约 20,081，分散效应约 32%。这是集团风险管理部讲「不要把风险都压在一个篮子里」的数字化表达：真实的相关矩阵让多元配置「省资本」。

§4第三步：实际资本与分级限额

实际资本 = 认可资产 − 认可负债 = 240,000 − 183,000 = 57,000
认可 ≠ 账面：资产按穿透后的认可价值计量（如部分长期股权投资、受限资产打折或不予认可），负债按监管口径（BEL + 风险边际等）。

资本分级与限额（案例）

层级案例金额特征
核心一级资本38,000普通股、留存收益等，损失吸收能力最强
核心二级资本（计入限额内）8,800受限于核心资本结构限额：超限部分（案例 1,200）不再计入核心，转列附属一级
附属一级资本1,200次级债等，吸收顺序靠后
附属二级资本9,000吸收能力最弱，且附属资本合计不得超过核心资本
实际资本合计57,000核心资本 46,800 + 附属资本 10,200

充足率：双线监管

指标算式案例监管线
核心偿付能力充足率核心资本 ÷ 最低资本 = 46,800 ÷ 20,081233%≥ 50%
综合偿付能力充足率实际资本 ÷ 最低资本 = 57,000 ÷ 20,081284%≥ 100%
风险综合评级 IRR操作 / 战略 / 声誉 / 治理等定性打分A 类B 类及以上
三条线全部达标才算偿付能力达标——综合充足率 284% 看似高枕无忧，但 IRR 若掉到 C/D 类照样触发监管措施。这正是「定量 + 定性」双支柱的设计意图。

§5第四步：压力测试与逆周期中频

考试常给一个冲击情景，问充足率掉到多少、是否破线。案例公司的三情景结果：
压力情景冲击设定核心充足率综合充足率判断
基准—233%284%达标
权益冲击股票 −30%189%231%仍达标
利率冲击利率 −100bp201%245%仍达标
逆周期叠加以上情景叠加逆周期因子165%201%最紧情景
答题套路：压力测试题三步走——①识别冲击传导渠道（资产端折价 / 负债端增值）；②重算 MC 与实际资本；③对照三条监管线给结论。利率下行对负债端（折现率下调 → 准备金上升）的杀伤往往大于资产端，这是「资产久期 < 负债久期」公司的通病。

§6第五步：双曲线（750 日 / 60 日）

曲线用于逻辑
750 日移动平均曲线准备金评估折现（CH.02）拉长观察窗、削平利率波动 → 负债计量「以稳为主」
60 日移动平均（短期端情景曲线）市场风险（利率风险）最低资本贴近当前市况、让资本对利率变化「有感」
实务视角：一套利率、两条曲线——负债用慢曲线求稳，资本用快曲线求敏。压力测试里常见「慢曲线负债 × 快曲线资产」的错位放大效应，案例公司利率 −100bp 掉 42 个百分点（233→201）就是这么来的。风险边际 RM=600（约当 BEL 4,200 的 14.3%）单独计入负债，是「非对称审慎」的体现。

IRR 评分权重（SARMRA 与定性评价合成，总分 100）：
维度权重案例得分口径
SARMRA 评估40%偿付能力风险管理能力
公司治理15%治理结构与运作
偿付能力数据与信息系统12%数据质量与穿透能力

合规风险13%监管处罚与整改

要点一句话：SARMRA 操作风险得分 40 分、评估与治理各 10 分量级的权重结构，信息披露与合规按细则计分，合成后定风险综合评级档次。
