§1为什么利润会「凭空出现」高频

定价时假定死亡率 3‰、费用率 10%、利率 2.5%；一年过去，实际发生的数据几乎不可能与假定分毫不差。假定与实际的差异，就是利润（或亏损）的来源——利源分析回答的是「这笔利润究竟是谁创造的」。
准备金的角色：定价时把未来的赔付、费用、利息都「预存」进准备金；期末实际发生额与预存额的差额，逐项退回利润表。所以利源分析的每一条都是「准备金中假定释放值 − 实际发生值」的格式。

§2大一统公式高频

利润 = 死差益 + 费差益 + 利差益 + 退保差益 + 其他利源
其中每项 = −（实际发生值）+（准备金中假定释放值）
「大一统」的含义：不管旧准则还是新准则、不管公司怎么设科目，利源恒等于这五块。准则改变的是「在哪个科目确认」，不改变「利润从哪来」。
利源公式正负号含义驱动部门
死差益(预定死亡率 − 实际死亡率) × 危险保额实际死亡 fewer → 正（益）核保 / 再保
费差益预定费用 − 实际费用实际花得更少 → 正（益）运营 / 行政
利差益(实际投资收益率 − 预定利率) × 责任准备金均值投资跑赢预定 → 正（益）投资 / 资产配置
退保差益(预定退保率 − 实际退保率) 对应的盈余实际退更少 → 正（益）继续率管理
其他利源分红特储释放、税差、再保摊回等视项目而定精算 / 财务
要点一句话：四差皆益则利润生——实际死亡低于预定、实际费用低于预定、实际投资跑赢预定、客户留存稳定；退保差为第五利源，最终在利润大一统公式中勾稽。

§3三差逐项细看

死差：危险的生意，稳定的利润

要点内容
计算基础危险保额（= 保额 − 准备金），不是保额本身——随着准备金积累，危险保额递减，死差贡献自然衰减
经验基础生命表（CL2010—2016 系列）+ 公司自身经验分析（CH.05 的暴露数 / 95%CI 工具）
改善路径核保收紧、逆选择控制、再保分出高危体

费差：短跑冲刺

获取费用（佣金）集中在首年，维持费用贯穿全程。费差益往往首年大亏、次年转正——与新业务价值的首年 Strain（VNB 专题 §5）互为镜像。降本增效的每一块钱几乎全部落入费差，这是 AI / 大数据在精算视角下最直接的利润入口。

利差：资产负债表的生意高频

拆分含义责任归属
基础利差负债成本（预定利率）之上的无风险利得负债端定价（预定利率定得越低，未来越从容）
配置利差主动配置（久期 / 信用 / 另类）创造的超出部分资产端投资能力
利差是双刃剑：预定利率定高了，利差倒挂（利差损）会持续多年——高预定利率保单的「利差损毒资产」是上一轮行业出清的教训。利率下行期，负债成本刚性 + 资产收益下行 = 利差被两头挤压。

§4SOE 报告的标准作答结构中频

Source of Earnings（利源分析报告）是考纲 CH.05 的常考简答。作答按五段式，缺一段丢一段的分：
段落内容常见追问
①说明分析对象与期间（产品组 / 业务单元，年度/季度）分组依据
②列示四差 + 其他利源的金额与方向（表格化）正负号含义
③逐项归因：预期变化还是实际经验偏离经验偏离 → 假设是否需要更新
④结论：利润质量判读（可持续 / 一次性）本期利差由一次性处置资产贡献 → 不可持续
⑤建议：假设调整、定价反馈、管理动作反馈到下一轮定价（CH.01 闭环）
实务视角：SOE 每季一报，真正的读者不是监管而是管理层——它回答「今年利润好，明年还会好吗」。归因时最忌把一次性收益（资产处置、准备金一次性释放）混入经常性利源，粉饰利润质量。

§5久期缺口与利差敏感性中频

经济价值变动 ≈ −(资产久期 − 负债久期) × Δr × 资产规模
案例：缺口 1 年 × 利率下行 100bp × 1,000 亿 ≈ 10 亿损失
资产久期 < 负债久期（行业常态）时，利率下行资产增值不如负债增值快，净头寸缩水。这就是利差背后的「结构性利差风险」。
情景传导净价值影响
利率 −100bp负债现值上升快于资产约 −10 亿
利率 +100bp反向，但幅度受凸性影响不对称约 +9 亿
信用利差走阔资产端折价，负债不动视持仓信用等级
串联考点：这条公式同时是 偿付能力专题 §5 利率压力（−100bp → 核心充足率 233%→201%）的底层机制——一个算经济价值、一个算监管资本，同一根久期缺口。

§6三条铁律与三个过滤器中频

三条铁律：
  • 保费不是收入——保费是负债的对价，收入只按履约进度确认（对接 IFRS17 专题 §4 的保险服务收入 736）。
  • 利润好 ≠ 利润质量好——归因结构比利润总额重要：利差占比过高的利润在利率下行期是「看天吃饭」。
  • 公司的未来靠新业务——存量利润终会释放完毕，NBV（VNB 专题）才是增量引擎。
三个过滤器问题指标落点
可复制性这个利差益明年还有吗？利源结构中经常性占比 / 经验稳定性
资本效率每元利润占用多少资本？ROE、要求资本回报（对接 偿付能力专题）
时间箭头利润是前置释放还是后置释放？CSM 摊销节奏 / 新业务 Strain

§7考试怎么考 + 演算器

真题痕迹：2014第4/19题、2016第22题均考利源分析框架。命题套路：给「定价假定 vs 实际经验」对照表 → 算三差 → 归因 → 判读利润质量。新准则下会加一问「实际/预期差异在新准则下进哪个科目」。
