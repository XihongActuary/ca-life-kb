§3.1偿付能力监管体系与分类监管基础

偿付能力 = 保险公司履行到期债务的能力。监管的一切工具，最终都指向「资本充足」这四个字（教材 §10.1）。

体系演进：从规模导向到风险导向

阶段特征局限
偿一代（2003前后的规模/倍数法）最低资本按保费/保额的一定比例计算与风险脱钩：业务越拼规模，资本要求越高，但不区分业务质量
偿二代一期（2016）三支柱风险导向框架确立部分风险计量偏松、资本工具认定偏宽
偿二代二期（规则Ⅱ，2022 施行）穿透到底、资本分级、保单未来盈余限额——（现行框架，考试主口径）

分类监管与动态测试（教材 §10.1.2–10.1.3）

  • 分类监管：按偿付能力达标状况对公司分类，采取差异化监管措施——不达标者面临限制业务、限制分红、强制增资、接管等措施；达标线＝核心充足率 ≥ 50%、综合充足率 ≥ 100%、风险综合评级 B 类及以上。
  • 动态偿付能力测试：不只看「今天够不够」，还要在压力情景下预测「未来还够不够」——这是压力测试（§3.9）的理论源头。
一句话贯通：静态充足率管「当下」，分类监管管「后果」，动态测试管「未来」。三层递进构成偿付能力监管的完整闭环。

§3.3认可负债评估（规则Ⅱ第3号）常考

偿二代不另起炉灶算负债，而是「以会计负债为基础、按认可标准调整」——负债评估的桥就这样架在 CH.04 之上。
认可负债 = 保险合同负债（会计口径经认可调整）+ 非保险合同负债
寿险合同负债 = 最优估计负债（BEL） + 风险边际（RM）
第3号：BEL 用即期国债曲线贴现（含 UFR 终极利率外推与综合溢价）；折现曲线详见 C-ROSS II 贯通页。
项目认可规则要点
最优估计负债 BEL未来现金流最佳估计的贴现值；利率风险计量用 60 日移动平均曲线
风险边际 RM偿二代口径的风险边际，与会计风险边际口径不同（监管统一规定）
非认可负债与偿付能力无关的负债（如应付款中非经营性科目）调整剔除
与 CH.02 关系法定准备金（精算规定）≠ 认可负债（第3号）≠ 会计负债（CAS25）——三口径并存，考试常考「同一个数字放哪张表」
易错：「认可负债=法定准备金」是错误表述。认可负债以会计负债为起点做调整；法定准备金是精算规定口径的负债——两者都服务于偿付能力，但计量路径不同。

§3.4保单未来盈余评估（专节）必考

考纲三明列「保单未来盈余评估」。这是偿二代二期最标志性的改革：未来利润可以计入资本，但分级、限额。

定义

保单未来盈余（Future Profits in Current Policies）：存量保单未来年度预期产生的、可用于吸收损失的盈余。它不是「已赚到的钱」，而是「未来才会赚到的钱」——把它计入资本的前提是：这些盈余最终能够真实吸收当期损失。

四档分级计入资本（规则Ⅱ第1号）

剩余期限计入资本层级损失吸收能力
> 30 年核心一级资本（CET1）最强（与实收资本同级）
10 – 30 年核心二级资本（AT1）强
5 – 10 年附属一级资本（T2）中等
< 5 年附属二级资本（T3）弱（与次级债同级）

两条限额约束

① 纳入核心资本的保单未来盈余 ≤ 核心资本 × 35%
② 核心二级资本 ≤ 核心一级资本 × 35%
规则Ⅱ第1号：防止把长尾未来利润过度提前计入资本、虚增核心资本——倒逼公司依靠真实股东投入与经营积累。

§3.5最低资本构成与计量原则核心

MC = MC可资本化 + MC控制 + MC附加
MC可资本化 = √[ Σ MCi² + 2Σρij·MCi·MCj ]（相关系数矩阵聚合）
可资本化 = 保险 + 市场 + 信用三类，先类内子风险聚合、再跨类矩阵聚合；控制风险 = 监管评价法；附加 = 逆周期+系统重要性。
条款（第2号）原则
第七条以风险为基础，涵盖可资本化固有风险、控制风险与系统风险
第八条相关系数矩阵法反映风险分散效应
第九条保险/市场/信用风险采用 VaR 法（一年期、99.5%）
第十条控制风险采用监管评价法
第十一条风险暴露不含非认可资产/负债
第十二条独立账户中保单持有人自担风险不计最低资本
第十三条特定安排致风险特征重大变动，监管可调整
第十四条长期寿险再保 3 年内可终止的不得计量资本降低；分出/分入对称
损失吸收效应（2015秋·10）：分红/万能保单持有人通过红利、结算利率吸收部分公司风险，最低资本可享最高 30% 的特征系数调整——答案 C.30%。

§3.7利率风险最低资本（演算器）核心

利率风险最低资本 = 利率上/下冲击情景下，负债与资产现值变动之差的最大非负值——本质是久期错配的资本化。
ΔPV ≈ −Dmod·Δy·PV；　MC利率 = max(0, ΔPVL − ΔPVA)，上/下行情景取大
D_mod 修正久期；情景冲击含综合溢价（如 50bp）。负债久期＞资产久期 → 利率下行时负债升值更多 → 缺口。
真题原型（2016·23）：给定 5 年负债现金流、可供出售债券与持有到期债券（各含面值/修正久期）、正常/上下行情景（综合溢价 50bp），求利率风险最低资本。演算路径：先分别求两情景下 ΔPVL、ΔPVA，再取最大非负缺口。

利率风险最低资本演算器

易错：①用修正久期而非麦考利久期；②资产负债分别取情景变动后再作差，不是久期直接相减；③两情景（上/下行）都要算，取大者——2016·23 的陷阱在「只算了一个方向」。

§3.8实际资本分级与充足率（演算器）核心

实际资本 = 认可资产 − 认可负债 = 核心一级 + 核心二级 + 附属一级 + 附属二级
综合偿付能力充足率 = 实际资本 / 最低资本；核心偿付能力充足率 = 核心资本 / 最低资本
达标线：综合 ≥ 100% 且 核心 ≥ 50% 且 IRR ≥ B 类。核心资本不含次级债等附属工具。
资本层级构成（寿险公司）限额
核心一级实收资本、资本公积、留存收益、剩余期限>30年保单未来盈余——
核心二级剩余期限10–30年保单未来盈余≤ 核心一级 × 35%
附属一级剩余期限5–10年保单未来盈余 + 符合条件资本工具≤ 核心资本 × 50%
附属二级剩余期限<5年保单未来盈余 + 次级债综合口径约束

§3.9压力测试与资本规划（专节）必考

考纲三明列「压力测试和资本规划」——两者是「发现问题 → 解决问题」的一对：压测找缺口，规划补缺口。

压力测试（规则Ⅱ第10号）

环节内容
情景设定监管情景（股票 −30%、利率 −100bp 等必测情景）+ 公司自设情景（巨灾、集中退保、业务大幅下滑）
量化传导情景 → 资产/负债重估 → 实际资本与最低资本同时变动 → 充足率变化
结果运用预测期（通常未来 1–3 年）内充足率跌破 100% → 触发资本规划与监管报告
与 EV 压测的区别偿付能力压测看「监管资本」，EV 压测看「经济资本」（2015秋·EV 压力测试题：调整后股东净资产 20.9、RC 15.6、VIF 234.6→216.6）

资本规划（规则Ⅱ第14号）

  1. 资本需求测算：结合业务规划与风险偏好，预测未来各年最低资本与实际资本缺口。
  2. 资本补充工具箱：股东增资（核心一级）、资本工具发行（二级资本债/永续债，注意各层级限额）、留存利润（不分红/少分红）、再保分出（风险缓释）、业务结构调整（降低资本消耗型业务）。
  3. 应急预案：触发条件（充足率跌破预警线）、责任人、启动时限、监管沟通路径。
答题模板（「作为精算师如何做资本规划」）：①测算缺口（压测）→ ②排工具（增资/资本工具/留存/再保/调结构）→ ③定触发线与应急安排 → ④报董事会并纳入 SARMRA 体系。四步成环，答题即满。
2014·26（真题原型，简答）题干：请简述经济资本的概念，说明其与监管资本的关系，并论述经济资本在公司内部管理（压力测试、资本规划）中的运用价值。
骨架：①经济资本=公司在给定置信水平（如99.5%）与期限内吸收非预期损失所需资本，公司自定；②监管资本=监管规则计量的最低要求；③经济资本≥监管资本时公司真正稳健；④压力测试与资本规划常以经济资本为内部标尺。
完整答题过程
问作答要点
①概念经济资本：在给定置信水平（如 99.5%）与期限（如一年）内，吸收非预期损失所需的资本量——由公司按自身风险状况与风险偏好自行计量，非监管强制
②监管资本按偿二代规则统一计量的最低资本：行业统一模型与参数、外部合规底线
③关系经济资本 ≥ 监管资本 ⇒ 真实稳健性高于监管底线；经济资本 ＜ 监管资本 ⇒ 靠监管口径「达标」，内部风险已超出自我承受意愿——管理信号劣化
④运用经济资本是内含价值 RC（专题·内含价值）、压力测试情景设定与资本规划缺口的内部标尺；监管资本回答「监管让留多少」，经济资本回答「自己该留多少」
溯源：2014 年真题第 26 题（回忆版）；经济资本与内含价值 RC 的关系见教材 §10 相关章节。

§3.10偿二代再保精算评估（专节）必考

考纲三明列「再保险合同精算评估」——偿二代视角下再保同时影响两端：降低最低资本（分出）与形成摊回资产，但设了「3 年可终止」的防火墙。
主题规则与要点依据
资本缓释边界长期寿险再保合同若3 年内可终止，分出人不得据此计量最低资本降低——防止「买一张再保单凑资本」的监管套利规规则Ⅱ 第2号第14条
第9号（信用风险）
题2016·21、2017·7、2013·共同再保
分出/分入对称分出方最低资本减少额与分入方增加额原则上一致，防止双边不对称计量
摊回资产摊回未决/未到期计入认可资产，但须评估再保人信用风险（第9号：评级越低折扣越大，评级低于阈值不予认可）
非比例再保超额赔款/停止损失合约按责任层单独评估巨灾资本缓释（PML 测试）
分出后净额法：MC(净) 基于「自留风险暴露」计量；摊回资产 = 再保人信用折扣后的摊回准备金
先验可终止性、再扣信用折扣、最后算资本缓释——三步顺序不可颠倒。
2013·再保（真题原型，简答）题干：请比较共同再保险（Co-reinsurance）与一年期可续保再保险在合同结构、定价机制与偿付能力资本缓释效果上的差异。
骨架：①共同再保：多家再保人按约定比例共担同一风险，长期绑定、无年度重新定价；②一年期可续保：按年度续签、费率可调整——正因「短期可终止」，其在偿二代下的资本缓释受限（呼应3年条款）。
完整答题过程
维度共同再保险一年期可续保再保险
合同结构多家再保人按约定比例共担同一风险池单一或少数再保人按年度续签
定价机制长期绑定，通常不随年度经验重定价每年按经验与市场状况调整费率
资本缓释长期不可终止 → 分出方可计量最低资本降低短期可终止 → 受规则Ⅱ第2号第14条约束，缓释受限
适用场景大额长期业务的风险分散与承保能力扩容年度波动管理、短期资本调节
溯源：2013 年真题再保险合同题（回忆版）；3 年可终止条款见规则Ⅱ第 2 号第 14 条。
一句话贯通：偿二代看再保，先问「能不能终止」——3年内可终止的资本减不了；再问「再保人靠不靠得住」——信用折扣先扣；最后才看「省了多少资本」。

自测真题印证与自测考前必做

先遮住答案独立作答，再展开核对——本章权重 30%，自测一道计算（矩阵聚合）+ 一道论述（未来盈余）。

自测 1（计算，12 分）：三类风险最低资本的相关矩阵聚合
某寿险公司分类计量的最低资本：保险风险 10,000、市场风险 8,000、信用风险 2,000（均为类内已分散）。跨类相关系数：ρ(市场,信用) = 0.25，ρ(保险,市场) = 0.0625，ρ(保险,信用) = 0.0625。
求：①聚合后的可资本化风险最低资本；②分散效应节约了多少资本。
①平方项：10,000² + 8,000² + 2,000² = 100,000,000 + 64,000,000 + 4,000,000 = 168,000,000（4 分）；
交叉项：2×0.25×8,000×2,000 = 8,000,000；2×0.0625×10,000×8,000 = 10,000,000；2×0.0625×10,000×2,000 = 2,500,000，合计 20,500,000（4 分）；
MC = √(188,500,000) ≈ 13,730（2 分）；
②简单加总 20,000 → 聚合后 13,730，分散效应节约 ≈ 6,270（约 31%）（2 分）。
评分要点：公式（含 2 倍交叉项）3 分、平方项 3 分、交叉项 4 分、开方结果 1 分、分散效应 1 分。
自测 2（论述，12 分）：保单未来盈余的分级计入逻辑与监管意图
请论述偿二代二期下保单未来盈余计入资本的制度安排：①为什么允许未来盈余计入资本；②为什么必须分级、分级规则是什么；③两条限额约束各自防范什么问题。
①存量保单未来盈余具有损失吸收能力（未来利润终将实现并可用于吸收当期损失），完全排除会低估寿险公司资本实力——这是寿险区别于银行业的资本来源特征（3 分）；
②盈余实现需要时间，剩余期限越短实现越确定：>30 年计核心一级、10–30 年计核心二级、5–10 年计附属一级、<5 年计附属二级——期限即「损失吸收的确定性等级」（4 分）；
③「核心层级 35% 限额」防止把长尾利润过度提前计入核心资本、虚增核心资本充足率；「核心二级 ≤ 核心一级 35%」防止核心二级对核心一级的稀释失控——两条限额共同倒逼公司依靠真实股东投入与经营积累（5 分）。
结论句：未来盈余是寿险公司独有的「时间换资本」机制——监管承认它，但用期限分级与 35% 限额给它套上缰绳。
