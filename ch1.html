§1.1评估的定义与三大基本问题概念

精算评估，是保险公司在特定目的与规则约束下，对未来现金流进行量化计量，从而回答「负债多少、资本够不够、公司值多少」的过程。

同一个存量业务，在不同目的下会得出不同数字——这不是矛盾，而是评估的多口径属性：目的决定规则，规则决定假设，假设决定结果。理解这一点是全科目第一块地基。

基本问题评估对象核心输出主要规则来源本库章节
欠多少（负债计量）有效保单未来给付义务责任准备金 / 保险合同负债精算规定 90·67·8·335·121 号；CAS25CH.02 / CH.04
够不够（资本充足）认可资产 − 认可负债核心/综合偿付能力充足率偿二代规则（偿付能力监管规则Ⅱ）CH.03
值多少（价值衡量）调整净资产 + 有效业务价值内含价值 EV / 新业务价值 VNB精算实务指引（EV 自由裁量）专题·内含价值
评估与定价的分野：定价面向「尚未卖出的未来」，用最优估计+风险边际+利润附加，追求充分、公平、合理；评估面向「已经生效的存量」，服从法定/会计/税收等外部规则。二者的假设可以不同——这正是利源分析（CH.05）产生「三差」的根源。

§1.2基本方法一：未来法高频

未来法从「评估日往后看」：准备金等于未来所有给付与费用的现值，减去未来所有净保费的现值。
未来法：Vt = PV(未来保险给付 + 未来维持费用) − PV(未来净保费)
流入与流出都取精算现值（考虑生存、死亡、退保概率），贴现用评估利率。教材 §9.1 原式。

未来法的特点

维度说明
实务地位法定准备金评估的主流方法，几乎所有长期险种评估均以未来法为基础（教材明确：未来法在实务中的应用更广泛）
信息需求只需评估日之后的现金流假设：死亡率、退保率、费用率、评估利率
敏感方向对贴现率与发生率假设高度敏感——利率下行 50bp，长期年金准备金可能上升数个百分点
天然适配GPV 充足性测试（121号）、CAS25 负债计量、内含价值 VIF，全部建立在未来法框架上
实务提示：万能险的「保单账户价值」本身是逐期递推结算出来的，属于过去法思想的产物；但万能非账户部分的评估（未来结算利益承诺）仍靠未来法兜底——两类方法在同一个产品里各司其职。

§1.3基本方法二：过去法（双算互证）常考

过去法从「评估日往回看」：准备金等于已缴净保费按评估利率的累积值，减去已付保险金的累积值。
过去法：Vt = [净保费累积至 t 时点] − [已发生给付累积至 t 时点] ＝ 净保费终值 − 给付终值
理论上与未来法结果恒等（现金流的会计恒等式），实务中因假设与计算路径不同而互为校验。

教材例 9-3 / 9-4：同一张两全保单，双法互证

项目取值说明
保单形态两全保险死亡给付与生存给付双重义务
年缴保费304.2 元题目给定毛保费口径下演算
评估利率5%用于现值/终值换算
死亡率q 随年龄 0.6% → 0.65% → 0.75%逐年递增，体现经验生命表特征
未来法结果315.3 元例 9-3：PV(未来给付) − PV(未来净保费)
过去法结果315.3 元例 9-4：净保费累积 − 给付累积，与未来法完全一致
判分要点：双法同值不是巧合，而是「准备金 = 已积累未了责任」的两种记账方向。答题时先写公式、再列现金流、最后两法并列对照，是最稳妥的展示结构。
双法关系一句话：未来法与过去法在理论上恒等——两法是同一条现金流的两种记账方向，实务中互为校验手段（见 §1.7 演算器）。

§1.4评估的分类：三大体系对照必背

按评估目的划分，准备金评估形成三大体系——法定、财务报告（会计）、税收。教材表 9-1 六行对照，是考纲「分类依据与结果」的直接考点。
对照维度法定评估财务报告评估（会计）税收评估
评估目的偿付能力监管，保护保单持有人公允反映经营成果与财务状况确定应纳税所得，税收公平
主要关注方监管机构（金融监管总局）投资者、债权人、分析师税务机关
准备金数额偏保守，通常不低于其他口径最佳估计 + 边际，相对中性依税法规则，防止利润操纵
假设取向监管统一规定（评估利率、生命表、修正方法）公司自定 + 准则约束（当前信息、不锁定折现率）税法法定，较少调整空间
评估方法净保费法 / 修正净保费法（FPT、Zillmer），统一性强现金流贴现 + 边际（剩余边际、风险边际），模型化程度高多在法定或会计口径上调整
复杂程度简单、统一、可复核最复杂（分组、锁定与解锁、摊销因子）相对简单，跟随性强
一图记忆：法定评估「稳」——规则统一，保守为先；会计评估「真」——反映真实经营，允许多空波动；税收评估「平」——削峰填谷，反避税。三体系回答三拨人：监管、投资者、税务机关。

§1.5各类评估的特点与相互关系特点

考纲一第三个考点「各类评估特点」——重点背法定评估三特点，再掌握各体系的衔接关系。

法定评估的三大特点（教材 §9.1）

特点含义为什么
简单易懂方法与假设全国统一，任何人可复核监管需要大规模可比：千家公司一把尺
相对公平不同公司、不同产品适用同一规则避免「挑规则」套利，保证同台竞技
相对保守评估利率、生命表均从审慎角度选取为极端不利情景预留安全垫，保护保单持有人

三体系的衔接关系（向下兼容，各有增量）

  • 法定 → 偿付能力：偿二代直接使用法定口径基础上的认可负债，叠加最低资本要求（CH.03）。
  • 会计 → 法定：CAS25 引入最佳估计+剩余边际+风险边际后，会计准备金与法定准备金差异显性化，差异本身就是监管「逆周期校准」的观察点。
  • 税收 → 会计/法定：税收口径通常以会计或法定结果为起点做纳税调整，不另起炉灶。
  • 数额差异的成因：折现率（法定锁定 vs 会计不锁定）、边际（法定含内含保守边际 vs 会计显性两边际）、假设更新频率（法定慢 vs 会计每年重估）。

骨架：①定价三原则（充足性/公平性/合理性）管「未来收多少」；②评估体系（保守性/统一性/可复核性）管「存量欠多少」；③定价不足终将表现为评估口径下的准备金缺口与资本侵蚀——两个环节共用同一套发生率与利率假设。
完整答题过程

第一部分：定价三原则（6 分）

原则内涵失衡的后果
充足性保费收入须足以覆盖未来给付、费用与合理利润——预定发生率、利率、费用率的估计不失真定价不足 → 准备金缺口 → 偿付能力侵蚀
公平性不同风险等级的投保人按各自风险缴对应保费，同质同价、异质异价逆选择：优质体流失、次标准体集中
合理性保费与给付责任、经营成本之间保持合理对应，不虚高牟利损害投保人利益、产品竞争力丧失

第二部分：与评估保守性的内在联系（6 分）

环节把关原则失衡后果
定价（事前）充足性 / 公平性 / 合理性费差损、利差损、逆选择
评估（事中）保守性 / 统一性 / 可复核性准备金缺口 → 偿付能力下降
偿付能力（事后）资本充足率红线监管介入、增资或停售
三环节闭环：定价假设失真 → 经验分析（CH.05）发现 → 评估假设更新 → 资本与产品策略调整。

结论句（背诵）：定价管「未来收多少」，评估管「存量欠多少」；定价的充足性对应评估的保守性——同源假设、互为镜像，定价失真终将在评估口径显形。

溯源：2014 年真题第 16 题（回忆版）；定价三原则见教材产品开发章节，评估保守性见 §9.1。

§1.6评估流程与假设体系底座

无论哪套体系，一次完整的精算评估都遵循同一套流程骨架，并共用三类假设。

六步流程（教材 §6.6 经验分析框架的推广）

  1. 确定观察期与范围：哪些保单、哪个评估日、哪个口径。
  2. 数据采集与筛选：剔除无效记录（如生效日晚于观察期末、日期非法）——2017 真题经验率分析题的核心步骤。
  3. 方法选择：未来法/过去法、逐单/分组、均衡净保费/修正法。
  4. 假设设定：经济、经验、行为三类假设，注意一致性（死亡率假设与核保规则、费用假设与费用分摊口径互相咬合）。
  5. 计算与校验：双法互证、上期滚动衔接、A/E 检验。
  6. 结果运用与报告：进入精算报告（45号编报规则，CH.05）。

三类假设（全科目通用的分类框架）

假设类别内容谁定更新频率
经济假设评估利率 / 投资收益率 / 通胀监管公布或市场基准（国债曲线+溢价）每年（会计）/ 锁定（法定）
经验假设死亡率 / 退保率 / 费用率 / 疾病发生率公司经验分析 + 行业生命表经验积累驱动
行为假设缴费弹性 / 部分领取 / 情景选择公司判断 + 历史行为定期复核
假设一致性三问（教材 §6.5「其他考虑」）：①死亡率假设与核保宽严是否匹配？②费用假设与费用分摊口径是否同源？③投资收益假设与资产配置是否对应？三问对不上，评估结果必然失真。

① 预定利率上限的四次下调（读懂利差损的监管逻辑）

时间规则普通型预定利率上限监管意图
1999 年保监会紧急降息窗口2.5%（一刀切）遏制高预定利率存量利差损（彼时银行利率快速下行）
2013 年保监发〔2013〕62 号（费率市场化改革）3.5%（特定产品可上浮 1.15 倍 ≈ 4.025%）还定价权于公司，激活产品创新
2019—2023 年窗口指导 + 银保监办发〔2019〕182 号延伸4.025% 叫停 → 3.5% 收紧低利率环境下防止新一轮利差损
2024 年起金发〔2024〕18 号：预定利率动态调整机制挂钩研究值（3.0%→2.5% 逐季联动）从「静态上限」走向「市场化联动」
深挖要点：预定利率每降一档，存量高预定利率保单的法定准备金不动（锁定），而新增资产收益率随行就市——利差损由此固化。这是理解 CH.03 利率风险资本与 CH.05 利源分析的历史底座。

③ 三口径数值方向的直觉（论述题素材）

自测真题印证与自测考前必做

先遮住答案独立作答，再展开核对——本章真题以概念论述为主，自测以计算+论述各一道闭环。

自测 1（计算，12 分）：双法互证——未来法 / 过去法各算准备金并判断口径一致性
某两全保单，评估日有关数据如下：未来给付与费用现值 2,860 元；未来净保费现值 1,735 元；已缴净保费按评估利率累积至评估日 2,180 元；已付给付累积至评估日 1,055 元。
求：①未来法准备金；②过去法准备金；③判断两法口径是否一致并说明理由。
①未来法：V = PV(给付+费用) − PV(净保费) = 2,860 − 1,735 = 1,125 元（3 分）；
②过去法：V = 净保费累积 − 给付累积 = 2,180 − 1,055 = 1,125 元（3 分）；
③两法差值 0 元，口径一致（2 分）；理由：两法是同一现金流的两种记账方向，理论上恒等，差值非零说明贴现率或发生率口径不同源（4 分）。
评分要点：公式书写 3 分、两法各 3 分、一致性判断与理由 4 分、结论表述 2 分。
自测 2（论述，12 分）：三大评估体系的差异、成因与衔接
评分要点：①按目的划分：法定（偿付能力监管，保护保单持有人）、财务报告（公允反映经营成果）、税收（确定应纳税所得）（4 分）；②至少四个维度的对照：目的 / 关注方 / 假设取向（锁定 vs 每年重估）/ 数额倾向（保守 vs 中性 vs 反避税）（4 分）；③成因：三套规则服务三拨人，规则决定假设、假设决定结果（2 分）；④衔接：偿二代以法定口径认可负债叠加最低资本；CAS25 引入两边际后与法定差异显性化，差异本身成为监管观察点；税收以会计或法定为起点做纳税调整（2 分）。
结论句：同一存量业务、三个数字，不是矛盾，而是「多口径属性」——目的决定规则，规则决定假设，假设决定结果。
